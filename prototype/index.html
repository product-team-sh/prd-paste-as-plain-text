    Paste chip

    Shows where the paste ends, when plain text and the formatted paste would look different.

    Where it sitsRule
    AnchorJust below the last pasted line, 4px under it, with its left edge where the paste ends. That is where the caret and the eye already are.
    SidewaysIf it would cross the editor's right edge, it moves left to sit 12px inside. It never leaves the email body.
    Room belowIf the paste ends near the bottom of the editor, the editor scrolls up until the chip fits below the paste. The chip never covers the pasted text. It can sit over the next line for as long as it is open.
    Scrolled awayIf the user scrolls the paste out of view, the chip stays pinned to the top edge of the email body, or to its bottom edge beside the badge (just above the badge when the editor is too narrow for both), so it is always in sight while it is open. It returns to the paste when the paste is back in view. Picking an option from a pinned chip scrolls the editor back to the paste and replays the tint, so the change is seen.
    LayersAbove the email text. Below the toolbar, the subject line, the badge, open menus and dialogs.
    Getting noticedIt rises in over 180ms with one soft blue ring. The pasted text gets a light blue tint that fades over 1.2s, so the paste and its chip are seen together. With reduced motion turned on: no rise or ring, and the tint still fades. At rest it keeps a grey-500 border (4.8:1 on white) and a blue clipboard icon, so it never reads as part of the toolbar. After any switch the tint plays again.
    MenuOpens below the chip, or above it when there is no room. It shifts left to stay inside the editor.
    KeyboardCtrl pressed on its own opens the menu with the ticked option focused, as in Word. Tab from the text also reaches the chip. Arrow keys move, Enter picks, Esc closes and returns to the text. The shortcut hint reads ⇧⌘V on a Mac and Ctrl+Shift+V elsewhere, in grey-600 (6.9:1 on the hover colour).
    Screen readersHeard once, politely: "Pasted as plain text. Press Ctrl for paste options." A switch is announced too.
    ClosesOn a key that changes the text (typing, Delete, Enter), Esc, the next paste or Ctrl+Z. Arrow keys, Tab and scrolling leave it open, so the paste can be checked first. A click in the text outside the paste closes it; a click inside the paste keeps it. A click outside the editor closes only the menu.
